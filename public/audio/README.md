- abstract-art-1.mp3 - Mô tả cho bức tranh Abstract Art 1

- modern-art.mp3 - Mô tả cho bức tranh Modern Art
- classical-portrait.mp3 - Mô tả cho bức tranh Classical Portrait

## Tạo file audio:

Để tạo file audio thực, bạn có thể:

1. Sử dụng text-to-speech như Google Cloud TTS, Amazon Polly, hoặc Azure Speech
2. Thu âm thực tế với micro
3. Sử dụng AI voice generation tools

File audio nên:

- Có chất lượng tốt (ít nhất 128kbps)
- Độ dài từ 30-60 giây
- Voice rõ ràng, dễ hiểu
- Có subtitle/transcript tương ứng
